# Overlap comparisons

Source review only. All compared families remain separate.

| Family | Tools | Decision | Decisive distinction |
|---|---|---|---|
| Entra sign-in views | Show Entra Sign-ins: Failed; Successful; Latest 10; Last 48 Hours; Other Clients | KEEP DISTINCT | Failed includes failure reason/error code; Successful includes Conditional Access; Latest 10 adds location and uses count rather than a time window. Other Clients covers seven days. A combined view would need explicit preservation of columns, ranges and filters. |
| Mail audit views | Audit Mail Access; Audit Mail Deletions and Moves; Show Mail Audit Details | KEEP DISTINCT | Access reads MailItemsAccessed over 10 days; deletion/move uses four other operations over 14 days. Details combines operations over 14 days and extracts fields but drops raw AuditData. Shared ResultSize 5000 is not equivalence. |
| Inbox rules and mailbox access | Review Mailbox Rules and Access; Audit Tenant Mailbox Access; Show Mailbox Summary | KEEP DISTINCT | Rules/access includes hidden inbox rules plus forwarding/delegation and supports selected mailboxes, list or tenant. Tenant mailbox access is a tenant review. Summary is a short single-mailbox property read. Broad source coverage is not a replacement for a minimal read. |
| Mailbox delegation readers | Show Mailbox Permissions; Show Mailbox Send As Delegates; Show Mailbox Send on Behalf Delegates | KEEP DISTINCT | Mailbox ACL rights/deny flags, recipient Send As rights and GrantSendOnBehalfTo are different authorization sources. The ACL reader was renamed rather than narrowed. |
| Mailbox delegation removal | Remove Mailbox Delegate; Remove Disabled User Mailbox Access | KEEP DISTINCT | Selected mailbox/delegate/right removal versus cross-mailbox cleanup for a disabled identity, with different eligibility and approval workflow. |
| Group member readers | Show Group Members; Show AD Group Members; Show Entra Group Direct Members; Show Distribution Group Members | KEEP DISTINCT | Broad workflow uses Graph, Exchange AND direct LDAP via DirectorySearcher, accepts multiple inputs and verifies CSV exports. Quick commands are source-specific direct reads. No proof that one can retire another. |
| Group owner readers | Review Tenant Group Ownership; Show Entra Group Owners; Show Distribution Group Owners | KEEP DISTINCT | Tenant group/ownerless review across Graph and Exchange versus one group owner read. Different population and presentation. |
| User membership readers | Show User Group Memberships; Show AD User Group Memberships; Show Entra User Directory Memberships | KEEP DISTINCT | Workflow combines AD/Entra direct groups with optional AD branch and batch inputs. Graph memberOf quick command returns directory object types, not only groups. AD principal membership has its own backend semantics. |
| Membership removals | Remove User Group Memberships; Remove User from AD Group; Remove User from Entra Group; Remove Distribution Group Member | KEEP DISTINCT | Guided multi-user eligible-membership cleanup versus explicit one-group operations and distinct authoritative systems. |
| Account lookups | Find User UPNs; Find Entra Users by Exact Display Name; Show Entra User Details; Show User Account Status | KEEP DISTINCT | Name/email/list resolver with partial option versus exact display-name match, known-UPN details or status/sign-in reporting. Different inputs and returned fields. |
| AD account detail reads | Show AD User Details; Show AD User Details with net user; Show AD User Password Last Set; Show AD User Password Expiry | KEEP DISTINCT | AD module details include lockout and password flags. net user /domain is an alternate built-in backend. Expiry requests msDS-UserPasswordExpiryTimeComputed; last-set-only is a focused quick read. |
| Account enable/disable/delete | Enable User Account; Enable AD User; Enable Entra User Sign-in; Disable User Accounts; Disable AD User; Block Entra User Sign-in; Delete User Accounts; Delete AD User; Delete Entra User | KEEP DISTINCT | Guided authoritative-directory and batch workflows differ from one-target snippets in selection, validation and confirmation. Similar mutation names do not establish equivalent safeguards. |
| User review workflows | Check User Before Deletion; Review Account Cleanup; Review Accounts and Sign-ins; BEC: User Risk Assessment | KEEP DISTINCT | Predelete dependency review, tenant cleanup, sign-in/stale-account options and one-account compromise assessment answer different decisions. Optional or unavailable sources must not be collapsed into equivalent coverage. |
| App consent removal | Remove User App Consent; Remove Delegated App Grant by ID | KEEP DISTINCT | User-specific guided grant selection/approval versus raw grant-ID removal. The latter must not be treated as an equally restricted replacement. |
| Authentication method reads | Show User Authentication Methods; Show Microsoft Authenticator Methods; Show Phone Methods; Show User MFA Registration Status | KEEP DISTINCT | General authentication methods, typed method endpoints and registration report are distinct. Registration status is not the same evidence as enrolled methods. |
| Licensing | Show User Licenses; Audit Tenant License Totals; Assign User Licenses; Remove User Licenses; Create Dynamic Group for Licensed Users | KEEP DISTINCT | User assignments, tenant seat totals, approved assignment/removal and dynamic membership-rule creation are separate jobs. Creating the group does not itself assign licenses. |
| Module setup | Install PowerShell Modules; Install Active Directory Module (RSAT) | KEEP DISTINCT | Combined choice-based setup versus standalone Windows RSAT setup/verification. Consolidation would need to preserve minimal install path and Windows feature behavior; not authorized as a consequence of renaming. |
| Azure resource reads | Show Azure Resource Groups; Test Azure Resource Group Access; Show Azure Owner Assignments | KEEP DISTINCT | Subscription resource-group list, access/resource read inside one resource group and Owner role assignments inspect different scope/data. |
| VPN views | Show Azure VPN Connection Status; Show Windows VPN Connections | KEEP DISTINCT | Azure gateway status in a selected tenant/subscription versus locally configured Windows VPN profiles. Neither demonstrates actual tunnel traffic. |
| Storage diagnostics | Find What’s Using Disk Space; Show Local Drive Free Space; Open Storage Settings; Open Disk Cleanup | KEEP DISTINCT | Folder-size ranking, fixed-drive capacity, settings launch and cleanup UI have distinct outputs/actions. |
| Windows repair utilities | DISM: Analyze Component Store; DISM: Scan Component Store; DISM: Repair Component Store; DISM: Clean Component Store; Repair Windows System Files with SFC; Scan File System with CHKDSK | KEEP DISTINCT | Space analysis, corruption scan, component repair, component cleanup, protected-file repair and file-system scan are different operations and change boundaries. |
| Network diagnostics and resets | Ping Host; Ping Host Continuously; Test Route Packet Loss with PathPing; Trace Route; Test TCP Port; Show Port 443 Connections; Reset Winsock; Reset TCP/IP Stack; Release and Renew DHCP Addresses | KEEP DISTINCT | Different protocol, sampling, route/connection evidence and reset layers. A token-similarity screen creates false positives from common confirmation wrappers. |
| Adapter controls | Disable Network Adapter; Restart Network Adapter; Disable All Active Network Adapters | KEEP DISTINCT | Selected adapter disable, selected adapter restart and all Up adapters disabled have materially different targets and blast radius. |
| Local versus domain identities | Show Local User Details; Show AD User Details with net user; Show Current Windows Identity and Privileges | KEEP DISTINCT | net user locally, net user /domain and current-token whoami interrogate different identities/authorities. |
| Certificates | Show Code-Signing Certificates; Show Expired and Expiring Certificates; Find Certificate by Thumbprint; Export Certificate as PFX; Export Public Certificate as CER | KEEP DISTINCT | Purpose-based certificate list, expiry filtering, exact lookup and private/public export are not interchangeable. Different stores and private-key exposure matter. |
| Windows event views | Show Recent Application Errors; Show Recent System Errors; Show Recent Windows Update History; Show PowerShell Script Block Events; Show Failed Windows Logons | KEEP DISTINCT | Separate logs, event IDs and windows; shared Get-WinEvent does not establish duplicate capability. |
| BEC workflow and standalone checks | BEC: User Risk Assessment; BEC: Contain and Eradicate; BEC: Restore and Validate; BEC: Revoke Sessions and investigation tools | KEEP DISTINCT | Assessment, approved containment, readiness/recovery and one-purpose investigation actions have distinct connection, identity, evidence and mutation boundaries. Alphabetical browse is not the workflow execution order. |
