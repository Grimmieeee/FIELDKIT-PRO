# Catalog naming standard

Approved November 18, 2026. Display names use action first: Show for direct reads, Find for lookup, Audit for audit records or exception review, Review for guided or broader interpretation. Preserve meaningful verbs for changes. Names must describe actual scope and must not imply stronger containment or source coverage than implemented.

Browse is alphabetical. Search retains intent ranking; former display names remain exact aliases. Filenames, stable IDs and embedded workflow headers remain unchanged in this display-only migration, except the Send As quick command adds its explicit AccessRights filter and four Entra group quick commands update their disambiguation message to the current tool title. Native script headers can retain historical executable names. This supersedes the older requirement for identical display and executable titles.

See NAMING-MAP.json for every approved rename and source-supported category move. Hybrid tools stay in AD where their authoritative-directory behavior is material; cloud-only identity tools move to Entra, multi-service tenant/group reports to Directory & Tenant Services. AD authOrig sender restriction inspection belongs in AD.

Mailbox Permissions retains all explicit rights and deny flags, preserving useful behavior. Send As remains its own task. No catalog entries or executable capabilities are retired by this pass.
